# 张家界文旅数据可视化大屏

面向文旅管理部门的**分析决策型数据大屏**：把张家界 2014–2024 年的游客与旅游收入、气温、空气质量，以及自行采集的携程景点评价整合在一起，回答“什么时候游客多、哪里口碑差、差在哪”。

技术栈：HTML + CSS3（flex 布局、渐变、动画、border-image）+ 原生 JS / jQuery + ECharts，rem 自适应（flexible.js，适配 1024–1920px）；数据处理用 Python（pandas、Selenium）。

## 页面

| 页面 | 文件 | 内容 |
|---|---|---|
| 综合指挥舱 | `dashboard/index.html` | 月均气温、四季天数、空气优良率、景区分布与口碑地图、外省客源 TOP9、差评原因 TOP5、好评高频词 |
| 产业健康度 | `dashboard/page2.html` | 国内/入境客流与旅游收入、游客与收入增速、人均消费、月度客流峰谷比 |
| 舆情治理 | `dashboard/page3.html` | 差评原因玫瑰图、气候人气节气盘、舆情河流图、分景点差评词、评论弹幕墙 |

## 快速查看

直接用浏览器打开 `dashboard/index.html` 即可（数据已预处理成 `dashboard/data/*.js`，无需后端）。推荐用 VS Code Live Server 打开。

## 数据处理流程（`data_processing/`）

| 脚本 | 作用 |
|---|---|
| `01_extract_zjj.py` | 从全国城市气温、空气质量原始数据中抽取张家界 |
| `02_crawl_ctrip_reviews.py` | Selenium 模拟浏览采集携程 5 个景点评价（随机间隔、不登录、遇到验证码即停止） |
| `03`–`06` | 月均气温、四季天数、空气优良率、张家界地理边界 |
| `07`–`15` | 景点口碑汇总、客源省份、差评原因分类（关键词规则）、词云、月度舆情、评论抽样等 |

处理结果直接写到 `dashboard/data/`。

## 关于数据

- `data/` 中保留了处理后的张家界气温、空气质量、游客与收入数据和评价总数统计。
- 全国气温（约 360MB）和地级市空气质量原始数据体积过大，未放入仓库。
- 携程评价原文涉及平台内容版权，**未公开原始采集文件**；大屏中展示的是汇总统计和截断后的少量匿名评论样本（不含用户名）。
